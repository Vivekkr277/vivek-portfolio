# Portfolio

Personal portfolio built with React (Vite), React Router, Tailwind CSS, Framer Motion, and React Icons.

## Getting started

```bash
npm install
npm run dev
```

## Stack

- **React + Vite** — build tooling
- **React Router** — routing (see `src/routes`)
- **Tailwind CSS v4** — styling (see `src/styles/index.css`)
- **Framer Motion** — animation
- **React Icons** — icon library
